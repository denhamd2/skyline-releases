# Reference Designs

Baseline UI reference designs for Sky Go, covering mobile and desktop/TV layouts.

These should be treated as a **baseline, not an exact spec** — sections and nav items
have been adjusted since these were produced, so implementations are not expected to
match pixel-for-pixel.

## Structure

- `mobile/mobile-screens.png` — mobile app screens (Home, Live, Player, TV Guide, Downloads, Account)
- `desktop/desktop-screens.png` — desktop/TV UI screens (Home, TV Guide, Continue Watching, Settings)

## Screens captured

### Mobile
- Home (Continue Watching, Live Now, Trending, Sports, Entertainment, Cinema, Kids)
- Live (All/Football/F1/Cricket/Tennis/Golf tabs, Up Next, Highlights)
- Player (full-screen video with playback controls, "More like this")
- TV Guide (day tabs, channel grid)
- Downloads (Smart Downloads toggle, storage usage, download list)
- Account (profile, My List, Recordings, Purchases, Parental Controls, Settings)

### Desktop
- Home (hero banner, Today's top picks, Browse, Sports)
- TV Guide (channel grid with time slots)
- Continue Watching / My List
- Settings

## Adding files

Drop additional source image files (PNG/JPG/Figma export) into the matching subfolder
above, named descriptively, e.g. `mobile/mobile-player.png`, `desktop/desktop-settings.png`.
