# skyline-releases

Source and distribution for **Skyline** — a Sky-Go-styled IPTV client for
Android phone and Android TV, built for one family.

- App source: [`skyline-iptv/`](./skyline-iptv)
- CI builds a debug APK on every push and publishes it to the
  [`skyline-latest`](https://github.com/denhamd2/skyline-releases/releases/tag/skyline-latest)
  release, which the in-app updater reads with no credentials.
- Design system docs live in [`docs/`](./docs); specs live in
  [`openspec/`](./openspec).
